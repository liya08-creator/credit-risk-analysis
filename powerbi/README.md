# Power BI Dashboard

File: `credit_risk_dashboard.pbix`
Data source: the PostgreSQL database (views and model result tables). Database credentials are not stored in this repository.

## Pages
1. **Credit Risk Overview:** total customers, defaulting customers, default rate, default vs non-default split, and a demographic overview (age group, gender, education).
2. **Customer Risk Analysis:** default rate by age group, education, marital status, repayment status, credit limit and risk tier.
3. **Machine Learning Performance:** model comparison (accuracy, precision, recall, F1, ROC-AUC), confusion matrix and feature importance.
