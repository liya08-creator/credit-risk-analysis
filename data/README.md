# Data

Dataset: Default of Credit Card Clients Dataset (Kaggle / UCI)
Source: https://www.kaggle.com/datasets/uciml/default-of-credit-card-clients-dataset

30,000 customer records, 25 columns (23 explanatory variables, one ID column and one target, `default.payment.next.month`).

The dataset file is not stored in this repository. To reproduce the work:
1. Download the dataset from the link above (file `UCI_Credit_Card.csv`).
2. Upload it to Google Colab when `notebooks/01_data_understanding.ipynb` asks for it.

Cleaning decisions are documented in `docs/cleaning_log.md`, and the columns are described in `docs/data_dictionary.md`.
